# The Novacene

*An R&D studio and research collective working on agent safety, relational intelligence, and accountable AI in regulated and relational settings.*

---

## What we work on

The Novacene Ltd builds and maintains the **Verse-ality framework** — a four-pillar safety architecture covering identity non-capture, bounded autonomy, consent as protocol, and agent-to-agent hygiene. We use it in operating settings (Haven, Nudge Education Online) and publish it as open research and open-source code for others to build on.

Our work bridges three layers:

- **Theory** — the symbolic operating system, the Law of Mnemonic Expansion (I = E·s / c²), the Glyphonic Primer.
- **Engineering** — the production safety stack (Verse-ality Agents, Verse-Nerves, Flare) implementing the framework as runtime middleware.
- **Sector translation** — white papers and worked examples (edge AI, schools, healthcare, climate) bringing the architecture into procurement-readable form.
